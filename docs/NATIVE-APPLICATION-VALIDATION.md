# 独立 C++ 游戏入口验证

[简体中文](NATIVE-APPLICATION-VALIDATION.md) | [English](NATIVE-APPLICATION-VALIDATION.en.md) | [实战录像验证](REPLAY-VALIDATION.zh-CN.md)

独立版本已完成游戏系统恢复、浏览器接入和发布包验证。在仓库根目录双击 `启动风神录C++重建版.cmd` 可访问 8090；日文与简体版均通过该入口运行。

入口 `site/runtime/native-worker.mjs` 仅装载独立 `th10-game.wasm`、DAT、音乐和预烘焙字体，不加载原版 EXE、D3DX DLL、JIT 或静态指令提升模块。开发服务器仍可用 `/?engine=native`。

## 当前结构

- `source/cpp/game`：人工恢复的游戏类及原格式 ANM/ECL/STD/MSG 解释逻辑。
- `source/cpp/platform/World*`：自机、敌人、弹幕、激光、道具、灵击、符卡、界面、录像、结算、提示和分数弹字的对象所有权与平台连接。
- `source/cpp/platform/Application*`：原版场景状态机、更新/绘制链、60 Hz 时序、帧率统计、配置、截图与退出保存。
- `source/cpp/platform/Credits*`：十二种结局与片尾演出的资源加载、文本、音乐和回调。
- 浏览器宿主：独立文件覆盖层、WebGL 2、PCM AudioWorklet、输入快照、字体像素及计时器。宿主 API 使用普通 Wasm 内存和不透明句柄。

## 本轮对照发现并修复的问题

1. 第四关 3D 敌人投影必须用原版恒等世界矩阵；使用动画管理器未初始化的矩阵会产生 NaN 和错误碰撞。
2. 换关加载屏障实际等待的是音乐命令队列首项，需要推进音频任务。
3. POINT 缩放以源像素左上角取样，重采样时须清除 XRGB 未使用位。
4. 默认 D3DX 缩放有顺序抖动，奇数行从右往左遍历；无尺寸变化时只转换格式。
5. 汉化结局含制表符，原字库漏烘焙控制字符；已从 Windows GDI 补齐两套字库的 15 个字号。
6. 场景接入层的屏幕效果应引用会话标志；FPS 统计必须遵守原版换关时清零有效/累计帧数的规则。
7. 第五关的密集帧超出原版诊断执行器默认的一千万指令额度。将单帧对照额度调整为有界的一亿后，14,000 帧全部通过；没有修改游戏逻辑或跳过比较。
