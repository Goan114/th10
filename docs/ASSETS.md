# 原作资源边界

[简体中文](ASSETS.md) | [English](ASSETS.en.md)

本项目的源码许可证不覆盖《东方风神录》原作数据、简体中文汉化数据或其他第三方资源。公开源码仓库不应提交 `site/data`；`.gitignore` 已将该目录设为本地内容。

## 合法持有者自行准备

使用者必须从自己合法持有、且当地法律与原权利条款允许使用的副本准备运行数据。维护者不通过源码仓库提供、代找或重新授权这些文件。

完整本地运行目录使用：

- `site/data/th10.dat`：日文版游戏数据；
- `site/data/th10c.dat`：可选的简体中文版本数据；
- `site/data/thbgm/0000.bin` 至 `1540.bin`：可选的原作 PCM 音乐数据，按 262,144 字节分块；缺少时运行时可以静音游玩。

GitHub Pages 在线版允许合法持有者直接在浏览器中导入 `th10.dat` 或 `th10c.dat`，并可选择导入 `thbgm.dat`。这些文件只保存在当前浏览器的 IndexedDB 中，网站不会上传它们。浏览器存储按站点来源隔离，也可能被浏览器清理，因此不能视为永久备份。

准确的文件摘要、音乐总长度和分块大小由 `site/manifest.json` 与 `release.json` 记录。`scripts/verify.mjs` 会核对完整本地交付内容；既没有导入资源、也没有本地资源的纯源码 checkout 不能通过完整交付校验或运行游戏。

## 源码仓库与完整本地包

| 内容 | 公开源码仓库 | 合法持有者的本地完整包 |
| --- | --- | --- |
| C++、浏览器宿主、构建脚本、文档 | 收录 | 收录 |
| 构建后的项目 Wasm | 可按发布策略收录 | 收录 |
| 原作 DAT、BGM、汉化数据 | 不收录 | 由持有者本地准备 |
| 录像验证结果与哈希 | 可收录 | 收录 |
| 无再分发许可的 `.rpy` 文件 | 不收录 | 持有者可本地验证 |

当前工作目录是一个已经准备好资源的本地完整包。`.gitignore` 只影响未来 Git 收录，不删除本机文件；`scripts/package.py` 仍可供合法持有者制作自己的本地完整归档。

不要把完整本地归档、`site/data` 或原始录像上传到公开 Release、对象存储或 CDN，除非上传者确实拥有相应再分发权。
